# Code of Conduct

## Our commitment

We want Kaizeval to be a project where people of any background and experience level can take
part without harassment. Everyone who participates in the repository, issue tracker, discussions
or any other project space is expected to follow this code.

## Expected behaviour

- Be respectful and considerate in every interaction.
- Assume good intent, and ask before you assume.
- Give and accept constructive feedback gracefully; critique the work, not the person.
- Take responsibility for mistakes and learn from them.

## Unacceptable behaviour

- Harassment, insults, personal attacks or discriminatory remarks of any kind.
- Sexualised language or imagery, and unwelcome advances.
- Publishing someone's private information without their explicit permission.
- Sustained disruption of discussions, or any conduct that would be inappropriate in a
  professional setting.

## Scope

This code applies in all project spaces and whenever someone represents the project in public.

## Reporting

Report unacceptable behaviour privately to the project maintainers through the contact listed on
the repository's GitHub profile, or by opening a private security advisory if no other channel is
available. Reports are handled confidentially. Maintainers will review every report and respond
with an action that is proportionate, which can range from a private warning to a permanent ban
from project spaces.
